## Overview

This project classifies English customer-review sentences as **Positive (1)** or **Negative (0)** and asks:

> How does review length affect Accuracy and Macro F1 for TF-IDF + Logistic Regression versus pretrained Sentence-BERT embeddings + Logistic Regression? Which method performs more consistently across Short, Medium, and Long reviews?

| Method | Features | Classifier |
|---|---|---|
| Method 1 (traditional) | TF-IDF word unigrams + bigrams | Logistic Regression |
| Method 2 (pretrained) | Frozen `all-MiniLM-L6-v2` Sentence-BERT embeddings (384-d) | Logistic Regression |

Both methods are tuned on the development set only and evaluated once on the same 452 held-out test reviews.

## Dataset

[UCI Sentiment Labelled Sentences](https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences): 3,000 sentences (1,000 each from Amazon, IMDb, and Yelp; 500 positive and 500 negative per source). The notebook downloads it automatically.

Preparation:
- Minimal cleaning (whitespace only); punctuation, capitalization, and negation are kept.
- Identical texts are grouped with a SHA-256 hash so duplicates never cross splits.
- Group-aware split, stratified by source and label (seed 42): **2,099 train / 449 dev / 452 test**.
- Length groups are fixed from the training set: **Short 1–7 words, Medium 8–14, Long 15+**.

## Results (held-out test set)

| Group | n | TF-IDF Acc | TF-IDF Macro F1 | SBERT Acc | SBERT Macro F1 | McNemar p |
|---|---:|---:|---:|---:|---:|---:|
| Overall | 452 | 0.8009 | 0.8008 | 0.8872 | 0.8871 | < 0.001 |
| Short | 160 | 0.8312 | 0.8304 | 0.9312 | 0.9312 | 0.005 |
| Medium | 146 | 0.8699 | 0.8697 | 0.8425 | 0.8425 | 0.52 |
| Long | 146 | 0.6986 | 0.6981 | 0.8836 | 0.8834 | < 0.001 |

- SBERT is significantly better overall and on Short and Long reviews; on Medium reviews the difference is not significant.
- Macro F1 range across length groups: **TF-IDF 0.1716**, **SBERT 0.0888**. SBERT is more consistent.
- Length and source are related (IMDb reviews are longer), so these results do not prove that length alone causes the differences.
